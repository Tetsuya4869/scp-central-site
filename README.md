# scp-central-site

16支部のSCP記事の読了状況・進捗・お気に入りを管理する React/Vite アプリです。

起動すると読了チェックリストを表示します。支部と番号帯を選び、番号・タイトルで絞り込みながら、読了チェックとお気に入りの星を直接操作できます。通常のSCPは既存シリーズの番号帯（EN・JPなどは1000件単位）、1000件を超える特殊一覧は1000件ごとに表示します。

「進捗」では全体・支部・シリーズ別の件数を確認でき、「お気に入り」からも読了を変更できます。検索や絞り込みで進捗の分母は変わりません。メモは記事行から、全体検索・後で読む・メモ検索・バックアップは「その他」から利用できます。

既存の読了・お気に入り・読了日・メモなどの保存キーとバックアップ形式を引き継ぎます。記録はブラウザ内に保存され、端末間ではバックアップを書き出し／読み込んで移行できます。

Node.js 22以降で実行できます。

```sh
npm ci
npm run dev
```

変更を確認するには、テストと本番ビルドを実行してください。プレビューは `/scp-central-site/` で開きます。

```sh
npm test
npm run build
npm run preview
```

検索の所要時間は `node --expose-gc scripts/benchmark-search.mjs` で計測できます。初回のインデックス生成と、生成後の検索時間・メモリ使用量を表示します。

本番ビルドでは生成物の内容からサービスワーカーのリビジョンを自動計算し、記事データの更新もオフラインキャッシュに反映します。キャッシュ番号の手動更新は不要です。
